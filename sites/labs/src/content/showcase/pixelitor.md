## What is Pixelitor?

Pixelitor is an advanced Java image editor with layers, layer masks, text layers, 110+ image filters and color adjustments, multiple undo and much more.

## What the demo includes

The demo runs the full Pixelitor editor in the browser, with a sample image already open so you can start right away. Draw with the brush and other tools, work with layers and masks, apply filters from the Filter menu, and step back with undo.

You can also edit your own pictures. Click the upload arrow in the title bar of the Pixelitor window to choose an image from your computer, then open it from the `/uploads` folder with File → Open. Your image stays in your browser.

## Technical details

The demo runs on the CheerpJ Java 25 runtime and executes the original, unmodified Pixelitor JARs.
