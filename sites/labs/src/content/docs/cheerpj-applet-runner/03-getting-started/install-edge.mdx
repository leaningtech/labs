This page takes you through installing the CheerpJ browser extension for applets in Edge.

<LinkButton

## Step 1

Go to the [extension's page in Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/cheerpj-applet-runner/ebfcpaoldmijengghefpohddmfpndmic) and click _**Get**_.

<div class="mx-24">![](/assets/applet-screenshots/store_edge.png)</div>

Edge asks you to confirm. Click _**Add extension**_.

<div class="mx-24">![](/assets/applet-screenshots/edge_dialogue.png)</div>

> [!info] About permissions
> The extension asks for no access to your sites when you install it. When you enable it on a site, the browser asks you to let it read and change that site, so it can run the site's applets.

## Step 2

Once the extension is installed, its icon appears to the right of the address bar. If it isn't there, click the puzzle-piece icon to list your extensions, open the extension's menu (three dots) and select _**Show in toolbar**_.

<div class="mx-24">![](/assets/applet-screenshots/edge_toolbar.png)</div>
