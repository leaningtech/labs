This page takes you through installing the CheerpJ browser extension for applets in Chrome.

## Step 1

Go to the [extension's page in the Chrome Web Store](https://chromewebstore.google.com/detail/cheerpj-applet-runner/bbmolahhldcbngedljfadjlognfaaein) and click _**Add to Chrome**_.

<div class="mx-24">![](/assets/applet-screenshots/store_chrome.png)</div>

Chrome asks you to confirm. Click _**Add extension**_.

<div class="mx-24">![](/assets/applet-screenshots/chrome_dialogue.png)</div>

> [!info] About permissions
> The extension asks for no access to your sites when you install it. When you enable it on a site, the browser asks you to let it read and change that site, so it can run the site's applets.

## Step 2

Once the extension is installed, its icon appears to the right of the address bar. If it isn't there, click the puzzle-piece icon to list your extensions, and pin the extension so it stays in the toolbar.

<div class="mx-24">![](/assets/applet-screenshots/chrome_toolbar.png)</div>
