This page takes you through installing the CheerpJ browser extension for Java Web Start in Chrome.

## Step 1

Go to the [extension's page in the Chrome Web Store](https://chromewebstore.google.com/detail/cheerpj-jnlp-runner/achnhggjjhnadfapkmgallnbmemdojdi) and click _**Add to Chrome**_.

<div class="mx-24">![](/assets/jnlp-screenshots/store_chrome.png)</div>

Chrome asks you to let the extension manage your downloads. Click _**Add extension**_.

<div class="mx-24">
	![Chrome Dialogue1](/assets/jnlp-screenshots/chrome_dialogue.png)
</div>

> [!info] About the downloads permission
> A Java Web Start application starts when the browser downloads its `.jnlp` file. The extension watches for those downloads: when one starts, it stops the download and runs the application in a new tab instead. It leaves other downloads alone.

## Step 2

Once the extension is installed, its icon appears to the right of the address bar. If it isn't there, click the puzzle-piece icon to list your extensions, and pin the extension so it stays in the toolbar.

<div class="mx-24">![](/assets/jnlp-screenshots/chrome_toolbar.png)</div>
