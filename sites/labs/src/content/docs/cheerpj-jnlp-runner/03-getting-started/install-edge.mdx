This page takes you through installing the CheerpJ browser extension for Java Web Start in Edge.

## Step 1

Go to the [extension's page in Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/cheerpj-jnlp-runner/dpleickbpchmkpkmicanfolmianepfhe) and click _**Get**_.

<div class="mx-24">![](/assets/jnlp-screenshots/store_edge.png)</div>

Edge asks you to let the extension manage your downloads. Click _**Add extension**_.

<div class="mx-24">![](/assets/jnlp-screenshots/edge_dialogue.png)</div>

> [!info] About the downloads permission
> A Java Web Start application starts when the browser downloads its `.jnlp` file. The extension watches for those downloads: when one starts, it stops the download and runs the application in a new tab instead. It leaves other downloads alone.

## Step 2

Once the extension is installed, its icon appears to the right of the address bar. If it isn't there, click the puzzle-piece icon to list your extensions, open the extension's menu (three dots) and select _**Show in toolbar**_.

<div class="mx-24">![](/assets/jnlp-screenshots/edge_toolbar.png)</div>
