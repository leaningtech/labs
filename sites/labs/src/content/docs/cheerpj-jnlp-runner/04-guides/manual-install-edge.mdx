title: Manual Installation in Edge
description: Install an unpacked build of the extension in Microsoft Edge, for testing a fix
---

This page shows how to install an unpacked build of the extension in Microsoft Edge.

> [!note] Important
> This is only for testing. When the store version doesn't work for you, we may send you an unpacked build to try a fix quickly. Use the store version otherwise.

## Step 1: Unzip the Extension

Start by extracting the extension file into a folder. Ensure that this folder includes the _**manifest.json**_ file, which is crucial for Edge to recognise and load the extension.

<div>![](/assets/manual-common-screenshots/jnlp_unzip_file.png)</div>

## Step 2: Open Edge Extensions Settings

Open the Edge extensions settings by clicking the three dots in the upper-right corner of the Edge browser, going to `Extensions` and then selecting `Manage Extensions`.

<div>
	![](/assets/manual-common-screenshots/edge_nav_to_manage_extensions.png)
</div>
<div>
	![](/assets/manual-common-screenshots/edge_nav_to_manage_extensions2.png)
</div>
Alternatively, you can type `edge://extensions/` in the address bar to go
directly there.

<div>![](/assets/manual-common-screenshots/edge_type_directly.png)</div>

## Step 3: Enable Developer Mode

Toggle the Developer mode switch at the bottom-left of the Extensions page to enable it. This step is necessary to load unpacked extensions.

<div>![](/assets/manual-common-screenshots/edge_toggle_developer_mode.png)</div>

## Step 4: Load the unpacked extension

Click `Load unpacked` and navigate to the folder where you unzipped your extension files. Select the folder and confirm to load the extension into Edge.

<div>
	![](/assets/edge-jnlp-manul-install-screenshots/edge_jnlp_select_folder.png)
</div>

## Step 5: Verify Installation:

Once installed, the ‘Extension successfully installed’ screen will pop up in a new tab.

<div>
	![](/assets/edge-jnlp-manul-install-screenshots/edge_jnlp_install_successful_popup.png)
</div>

You can now manage the settings or remove it from this page:

<div>
	![](/assets/edge-jnlp-manul-install-screenshots/edge_jnlp_finish_install.png)
</div>
