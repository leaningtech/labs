---

CheerpJ licences are based on who uses the application. The extension is covered by a Desktop licence, priced by the desktops whose browser runs it. One licence covers both CheerpJ browser extensions, for applets and for Java Web Start, on that desktop. [Compare licences and prices][licensing].

## Community

Free, for personal, educational and hobby use, and for technical evaluation.

- Public Java Web Start applications for personal use.
- Technical evaluation, for organisations of any size.

## Desktop

For individuals and small teams using Java Web Start applications at work. A monthly subscription for 1 to 20 desktops, priced per desktop per month and [bought online](/docs/cheerpj-jnlp-runner/getting-started/activate-license).

- Business use, including Oracle Forms and E-Business Suite on internal networks.
- Any number of applications on a desktop.
- Updates on the regular release schedule.

## Enterprise

For organisations rolling the extension out across departments. Quoted on volume, from 21 desktops: [contact us][contact]. On top of Desktop, it adds:

- No licence server: fully self-hosted and air-gappable, with self-reported desktop counts.
- Deployment through Group Policy and Chrome and Edge policies, with offline licence tokens.
- Out-of-cycle updates and fixes.
- An optional support agreement, with 24-hour and 48-hour SLAs.
- Multi-year and perpetual terms.

## Examples

- You run a public educational Java Web Start application at home. **Community.**
- You are a student running Java Web Start applications for a personal project. **Community.**
- You are a developer checking whether your company's applications run, before deciding anything. **Community (technical evaluation).**
- You use an internal or customer-facing application at work, such as Oracle Forms or E-Business Suite, on up to 20 desktops. **Desktop.**
- You work in a public-sector organisation and use an internal application. **Desktop**, or **Enterprise** from 21 desktops.
- Your organisation wants to host the extension itself, on a network that can't reach the stores. **Enterprise.**

## Technical evaluation

A technical evaluation is any use where the application isn't in production, such as:

- testing applications on non-public systems;
- checking whether your applications run with the extension, for a possible project.

It doesn't include staff or customers using the application for their work.
