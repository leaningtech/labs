Forms Demo

A Forms/EBS-style purchase order screen running in the browser with CheerpJ: one 20 KB plain AWT JAR, built to boot as fast as possible. README

Starting CheerpJ…
  • Click a field and type. Tab, Enter and the arrow keys move between fields and lines.
  • F9 or … opens a list of values (Supplier, Site, Currency, UOM).
  • Change a Quantity or Price: line amounts and the total update as you type.
  • Ctrl+S saves. The toolbar arrows switch records; Approve locks a PO (record 2 starts out approved).
